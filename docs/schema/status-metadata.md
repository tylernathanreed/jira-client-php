| Property | Type | Description |
| --- | --- | --- |
| `category` | `'TODO'\|'IN_PROGRESS'\|'DONE'\|null` | The category of the status. |
| `id` | `string` | The ID of the status. |
| `name` | `string` | The name of the status. |
