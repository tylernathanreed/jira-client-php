# Attachment Metadata

Metadata for an issue attachment.

Source: [`Jira\Client\Schema\AttachmentMetadata`](/src/Schema/AttachmentMetadata.php)

| Property | Type | Description |
| --- | --- | --- |
| `author` | `` | Details of the user who attached the file. |
| `content` | `` | The URL of the attachment. |
| `created` | `` | The datetime the attachment was created. |
| `filename` | `` | The name of the attachment file. |
| `id` | `` | The ID of the attachment. |
| `mimeType` | `` | The MIME type of the attachment. |
| `properties` | `array<string,mixed>` | Additional properties of the attachment. |
| `self` | `` | The URL of the attachment metadata details. |
| `size` | `` | The size of the attachment. |
| `thumbnail` | `` | The URL of a thumbnail representing the attachment. |
