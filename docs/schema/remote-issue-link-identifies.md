# Remote Issue Link Identifies

Details of the identifiers for a created or updated remote issue link.

Source: [`Jira\Client\Schema\RemoteIssueLinkIdentifies`](/src/Schema/RemoteIssueLinkIdentifies.php)

| Property | Type | Description |
| --- | --- | --- |
| `id` | `` | The ID of the remote issue link, such as the ID of the item on the remote system. |
| `self` | `` | The URL of the remote issue link. |
