# Screenable Tab

A screen tab.

Source: [`Jira\Client\Schema\ScreenableTab`](/src/Schema/ScreenableTab.php)

| Property | Type | Description |
| --- | --- | --- |

| `id` | `int` | The ID of the screen tab. |
